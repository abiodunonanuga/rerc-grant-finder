## Microsoft Visual C++ Runtime

RERC-e does not redistribute Microsoft Visual C++ runtime DLLs. If the standard x64 runtime is missing, the launcher downloads the current installer from Microsoft at <https://aka.ms/vs/17/release/vc_redist.x64.exe>, verifies its Microsoft Authenticode signature, and runs the installer. Microsoft supplies and licenses that runtime directly to the user.

## Microsoft Edge WebView2

The Windows package includes the Microsoft.Web.WebView2 SDK version 1.0.4191.47 (Core and WinForms libraries and the x64 loader). Its license and notice are included as `licenses/WEBVIEW2-LICENSE.txt` and `licenses/WEBVIEW2-NOTICE.txt`. The WebView2 Evergreen Runtime is supplied separately by Microsoft. If it is missing, RERC-e offers to download Microsoft's bootstrapper, verifies its Authenticode publisher signature, and runs it before opening the app window.
